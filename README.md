# fta-system
FTA System is a web platform designed to calculate and determine the origin of products in compliance with Rules of Origin (ROO) under free trade agreements.

# Core Features
- ERP Data Integration: Retrieves key data from company ERPs, including items, suppliers, sales, purchases, customers, and Bills of Materials (BOM).
- Automated Origin Determination: Uses registered HS codes and Product Specific Rules (PSR) to verify whether products meet origin requirements.
- Supplier Portal: Allows suppliers to submit origin declarations and required documentation directly through the platform.

## Key Benefits

| Feature                | Benefit                                                    |
|------------------------|------------------------------------------------------------|
| Centralized ERP data   | Access accurate, up-to-date information in one place       |
| Compliance verification| Ensure products qualify under specific ROO criteria        |
| Supplier portal        | Streamline collection of declarations and documentation    |
| Process automation     | Reduce manual errors and accelerate FTA-related workflows  |

---

This system aligns with professional trade compliance solutions in the market, offering robust integration with ERP systems, automated multi-agreement origin calculations, and supplier-facing declaration portals — similar to industry tools like **Thomson Reuters ONESOURCE FTA** or **MIC Origin Calculation System**.
